# Press Layout Package

This package is a split version of your press layout GUI.

## Included behavior
- Bottom-centered control row
- Adjustable print margins
- Landscape default in the print dialog
- Color Pages / Plates visible on print
- Print / Save / Save As / Color Select hidden during print capture
- In Press 1 layouts, unused E2 / D2 / C2 units are temporarily hidden during print capture and therefore do not print

## Run
```bash
python run_press_layout.py
```
